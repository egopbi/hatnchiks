# Режимы и детерминированный процесс работы агента

## Роли и режимы

* **READ-ONLY:** поиск, индексация, выделение фактов, построение плана.
* **WRITE:** детерминированное применение согласованного плана.

## Обязательная последовательность

`READ-ONLY → План → Подтверждение инвариантов → WRITE → Самопроверка → Коммит/PR`

## План и применение изменений (детерминированно)

1. **Индексация кода** в разрешённых путях; сбор карты модулей/зависимостей.
2. **Минимальный дифф:** выбрать наименьший объём правок, достаточный для выполнения критериев приёмки.
3. **Подтверждение инвариантов качества** (линт/формат/типы/архитектурные слои).
4. **Пошаговый план:** *файл/участок → изменение → причина → риск/откат*.
5. **Проверка `.gitignore`** для каждого шага (аналог `git check-ignore`).
6. **Применение по плану** без отступлений и “улучшений по дороге”.
7. **Запуск проверок:** форматтер, линтеры, типы, тесты.
8. **Самоаудит диффа** по чек-листам (минимальность, отсутствие лишних переименований, стиль).
9. **Упаковка результата:** Conventional Commits + шаблон PR (ссылка на задачу, изменения по файлам, «почему так», риски/откат, чек-лист автора).

## Результат шага

* Повторяемость и трассируемость действий агента.
* Минимизация регрессий и ускорение ревью.
* Соответствие правилам безопасности и стилю проекта.
