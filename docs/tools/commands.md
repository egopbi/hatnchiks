# Инструменты и команды

## 1. Базовые команды проекта

> Если команда не определена в проекте — **не выполнять** замену самовольно; зафиксировать в отчёте раздел «Неопределённые команды».

### Форматирование

```bash
uv run ruff format
```

### Линтинг

```bash
uv run ruff check
```

### Тесты

```bash
uv run pytest -q
```

### Локальный запуск сервиса

```bash
uv run uvicorn main:app --host 0.0.0.0 --port 8000
```

## 2. Проверка путей против .gitignore

Перед **каждой** записью файла проверить соответствие `.gitignore`. Рекомендуемый способ — использовать эквивалент `git check-ignore <path>` или встроенный алгоритм сопоставления паттернов. Если путь игнорируется — **отклонить изменение** и зафиксировать причину в отчёте.

## 3. Сеть и зависимости

* Сетевой доступ запрещён, кроме получения зависимостей строго по lock-файлам (`uv.lock`).
* Любые отклонения от стандартных команд должны быть покрыты задачей и задокументированы в PR.
